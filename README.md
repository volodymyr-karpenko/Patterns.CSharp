# Patterns.CSharp

The project demonstrates 23 GoF software design patterns via C# programming language using simplistic examples.

### Important

All of the Patterns are located in `Patterns` directory.
The `UseCase` class and its base class `PatternUseCase` are related to none of the patterns and were created to deliver the output, produced by a pattern.

### View Output

Execute `dotnet run --project ConsoleApp/ConsoleApp.csproj` (if your OS is Windows, replace a forward slash with a backslash).
Enter pattern name (e.g. Chain Of Responsibility).
